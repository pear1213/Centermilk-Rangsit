# Center Milk สาขารังสิต — เว็บสั่งสินค้า

## เปิดยังไง
- **ดูเร็วๆ:** ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้เลย
- **ใน VS Code:** File → Open Folder… → เลือกโฟลเดอร์นี้
  - แนะนำลง extension **Live Server** แล้วคลิกขวา `index.html` → *Open with Live Server*
    แก้โค้ดแล้วกดเซฟ หน้าเว็บจะรีเฟรชเอง

## ไฟล์ไหนทำอะไร
```
index.html      โครงหน้าเว็บ + ลิงก์ฟอนต์
css/style.css   สี ฟอนต์ ขนาด หน้าตาทั้งหมด
js/config.js    ⭐ ตั้งค่าร้าน: ชื่อ เบอร์ พร้อมเพย์ ช่วงเวลา โลโก้ ค่าส่งเริ่มต้น
js/data.js      สินค้า + หมวดหมู่ "ตั้งต้น" (ใช้ตอนเปิดครั้งแรก)
js/app.js       การทำงานทั้งหมด (มีสารบัญ [1]–[15] อยู่บนสุดของไฟล์)
```

## อยากแก้... ไปที่ไหน
| อยากแก้ | ที่ไหน |
|---|---|
| เบอร์ร้าน / พร้อมเพย์ / ช่วงเวลาให้เลือก | `js/config.js` |
| สีหลักของเว็บ | `css/style.css` → `--blue` ใน `:root` |
| ฟอนต์ | ดูหัวข้อ "เปลี่ยนฟอนต์" ด้านล่าง |
| ข้อความบนหน้าเว็บ | `js/app.js` กด Ctrl+F ค้นคำไทยนั้น จะเจอแบบ `L("ไทย","English")` แก้ได้ทั้งสองภาษา |
| ราคา / ชื่อสินค้า / รูป / หมวด | **แก้ในเว็บได้เลย**: ล็อกอินแอดมิน → หลังร้าน → สินค้า/หมวด |
| ชื่อลูกค้า / ค่าส่งประจำ | ล็อกอินแอดมิน → ฐานลูกค้า |

### แก้ในเว็บ (โหมดแอดมิน) vs แก้โค้ด
- **งานประจำวัน** (เปลี่ยนราคา ใส่รูป ซ่อนของหมด เพิ่มหรือเปลี่ยนชื่อหมวด เรียงลำดับหมวด) → แก้ใน **โหมดแอดมิน** ง่ายกว่าและไม่ต้องแตะโค้ด
- **โครงสร้าง / หน้าตา / ฟีเจอร์ใหม่** → แก้โค้ด
- ⚠️ ถ้าแก้ `js/data.js` แล้วอยากให้เว็บโหลดสินค้าใหม่ ให้เปลี่ยน `DATA_VERSION = 1` เป็น `2`
  (สินค้าและหมวดที่แก้ในโหมดแอดมินจะถูกแทนที่ด้วยไฟล์ แต่ออเดอร์และลูกค้ายังอยู่)

## ใส่รูปสินค้า
1. **ในเว็บ:** แอดมิน → สินค้า/หมวด → กดที่สินค้า → 📷 อัปโหลดรูป หรือวางลิงก์รูป
   ระบบย่อรูปให้อัตโนมัติ แต่พื้นที่เบราว์เซอร์มีประมาณ 5MB ใส่ได้ราวๆ 100 รูป
2. **ในโค้ด:** เอารูปใส่โฟลเดอร์ `img/` (สร้างเอง) แล้วใน `js/data.js` ใส่ `"img": "img/milk.jpg"`
   แล้วเพิ่ม `DATA_VERSION` ขึ้นหนึ่งเลข

## เปลี่ยนฟอนต์
1. ไปที่ fonts.google.com เลือกฟอนต์ เช่น `Kanit`, `Prompt`, `Anuphan`, `IBM Plex Sans Thai`
2. ใน `index.html` เปลี่ยน `family=Noto+Sans+Thai` เป็นชื่อฟอนต์ใหม่ (ช่องว่างใช้ `+`)
3. ใน `css/style.css` เปลี่ยน `--font: "Noto Sans Thai", ...` เป็นชื่อฟอนต์ใหม่

> อยากรู้ว่าเว็บไหนใช้ฟอนต์อะไร: เปิดเว็บนั้นใน Chrome → คลิกขวาที่ตัวหนังสือ → Inspect →
> แท็บ **Computed** → ดูบรรทัด `font-family`

## ข้อจำกัดของเวอร์ชันนี้
- ข้อมูลทั้งหมด (ลูกค้า ออเดอร์ สินค้า) เก็บใน **เบราว์เซอร์เครื่องเดียว** (localStorage)
  ลูกค้าเครื่องอื่นจะไม่เห็นข้อมูลชุดเดียวกัน ถ้าจะใช้จริงต้องมีฐานข้อมูลกลาง เช่น Firebase หรือ Supabase
- รหัสผ่านเก็บแบบไม่เข้ารหัส ใช้ได้แค่ทดลองเท่านั้น
- ล้างข้อมูลกลับเป็นค่าเริ่มต้นได้ที่: แอดมิน → ออเดอร์ → รีเซ็ตข้อมูลทดลอง
